# Engineering memory

Maintained by `bld-engineering-memory`. Agents read this before starting so they build on the project record instead of re-deriving or contradicting it. Each entry: id, statement, evidence tag (PROTOCOL.md §1), source, date, status.

- `assumptions.md`: open assumptions and who must confirm them
- `decisions.md`: decisions with options, evidence and what would reopen them
- `lessons.md`: errors found and the check that now prevents them
