# Failure Precedents → Lessons for this project

Read the primary reconnaissance and inquiry reports before citing specifics. Question asked each time: *what design decision allowed this mechanism?*

| Mechanism | Well-documented in (verify with reconnaissance reports) | Design decision that allowed it | Lesson applied here |
|---|---|---|---|
| Soft / weak storey | Many RC buildings in Kobe 1995, Kocaeli 1999, Northridge 1994 (tuck-under parking) | Open ground storey, stiff upper storeys | Cores continuous to foundation; check L0 (5.5 m) gravity columns for drift compatibility |
| Torsional irregularity | Corner and eccentric-core buildings in many events, e.g. Mexico City 1985 | Lateral stiffness concentrated on one side | **CR-003**: balance the plan |
| Brittle column / wall shear | Short columns and squat walls, repeatedly | Shear strength below flexural capacity | Capacity-design squat cores for shear |
| Weak beam-column / connection | Steel moment connection fractures, Northridge 1994; poorly detailed RC joints, Christchurch 2011 | Untested brittle connection details | Use tested or code-qualified connections for CLT-to-core and diagrid nodes |
| Diaphragm / collector failure | Buildings with large floor openings and missing ties | Floor openings, no chords/collectors | Design collectors at the U-shaped floor and notch corners |
| Pounding | Mexico City 1985 | Insufficient separation | Set separation when neighbours are known |
| Liquefaction | Niigata 1964, Christchurch 2010–2011 | Shallow foundations on saturated loose sands | Investigation first; ground improvement or piles if found |
| Non-structural failure | Ceilings, glazing, sprinkler pipes in almost every major event | Unbraced components | Brace ceilings, ducts, sprinkler mains; drift-tolerant glazing |
| Progressive collapse | Ronan Point 1968 | No alternate load path | Robustness check for diagrid nodes and perimeter columns |
